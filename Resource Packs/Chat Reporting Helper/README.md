# Chat Reporting Helper

Minecraft's default in-game wording about chat reportability is technical, confusing and gives the assumption that chat reportability exists in every server. 
This resource pack fixes it by replacing those phrases with simple and accurate phrases.

### What this resource pack does

This resource pack changes various phrases in-game:

- chat indicator tooltips
- report button label
- "Messages can't be verified" warning toast text
- "Only Show Secure Chat" label and tooltip
- report reason textbox placeholder
- Realms introduction text (adds a new section)
- chat restriction descriptions

Goals:

- Ensure the phrases are short, clear and non-technical
- [Available in several languages](https://crowdin.com/project/fabulously-optimized)
- Be an educational tool, not a protective one
- Focus on practical use cases and actual server behavior, not theoretical possibilities
- Serve as an example and call to Mojang to improve transparency and clarity regarding this feature in the game

<details>
<summary>What this resource pack does not do</summary>

- Give opinions on whether chat reportability is good or bad
- Obstruct or mislead the meaning of any phrase
- Edit the "other players" button
- Edit report or ban reasons
- Edit the ban screen
- Hide chat indicators or warning toast
- Modify any kind of game functionality
- Replicate the features of any mod or plugin

</details>

### Who is this resource pack for

- Users, who don't understand how chat reportability works
- Users, who don't understand when and where chat reportability works
- Users, who are positive, neutral or slightly concerned about chat reportability 
- Users, who don't understand the technical terms related to chat signing
- Modpacks, that want to ensure users know about chat reportability and where it works
- Parents, who want to ensure their children play on servers that enforce chat reportability
- Realm owners, who want to know the limitations and requirements of Realms
- Server owners, who enforce chat reportability and want to ensure users know how it works

### Even more questions

> **Q**: Does this replace every chat reportability-related phrase and icon?
>
> **A**: No, only the minimum strings that are required for clear understanding.

> **Q**: Does this support any related mods?
>
> **A**: As of version 7.0, mod support has been removed. [Click for more info](https://github.com/Fabulously-Optimized/fabulously-optimized/issues/1205)

> **Q**: I don't see the changed phrase where I should see it.
>
> **A**: That might be due to a lack of resource pack translation in your language, so default phrases are displayed as a fallback. [Please contribute!](https://crowdin.com/project/fabulously-optimized)

> **Q**: Can I contribute translations to my language?
>
> **A**: Yes, please do! [Join the Crowdin project](https://crowdin.com/project/fabulously-optimized) and start translating.

> **Q**: Backports?
>
> **A**: No. This is intended for Minecraft 1.19.4 and up, because there have been major implementation changes compared to 1.19.3 and older.
